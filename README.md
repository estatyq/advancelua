# Universal Helper Platform v2.6

Универсальный игровой помощник для **GTA San Andreas — SA-MP** (сервера Advance RP).  
Построен на **MoonLoader** (Lua) с GUI **mimgui**, событиями **SAMP.Lua** и **SAMPFUNCS**.

[English version](README_EN.md) | [Дорожная карта](ROADMAP.md) | [Инструкция по эксплуатации](INSTRUCTION_RU.md)

---

## Возможности

### Конструктор локаций `/location` — полный бесплатный аналог *TitanLocation* (`location_builder`)
- **Каталог 522 объектов (`/loc 1` / `/tloc 1`)**: все 522 официальных ID объектов со страницы `adv-rp.com/decor` в 7 категориях, поиск по ID и названию, сортировка, избранное, недавние, компактный/карточный режим и опциональная подгрузка превью-картинок в `moonloader/config/decor_cache/`
- **Точный редактор поверх штатного `/location` (`/tedit`, `/tcopy`, `/tpaste`, `/tdup`)**: живой локальный предпросмотр через `sampGetObjectHandleBySampId` / `setObjectCoordinates` / `setObjectRotation`, сдвиг по `X/Y/Z` (`0.01–2.0`), поворот по `RX/RY/RZ` (`1°–90°`, горизонт), Undo/Redo до сохранения, копирование и вставка (всё / только `Z` / только углы / со смещением для стыковки стен) и дубликат объекта
- **Реестр сохранённой локации (`/loc 2` / `/tloc 2`)**: сохранение объектов в `helper_locations.json` по серверу и персонажу по факту серверного сохранения, пошаговый помощник правки/удаления из середины списка и экспорт/импорт чертежей (`helper_loc_blueprint.json`)
- Автоматический резерв `/tloc`, если команда `/loc` уже занята

### МВД, МЗ и Старший состав (`faction_tools`, `lecturer`, `gnews`)
- **МВД (`/suw [ID]`)**: редактируемый справочник УК (20 статей) и АК (10 статей) с пресетами серверов Blue / Red / Green / Chocolate (`helper_codex.json`), 1-клик РП + `/su` или `/ticket` (ручной `/su` не тронут), опциональное Авто-РП на `/cuff`, `/uncuff`, `/search`, `/putpl`, `/arrest` и 4 пресета мегафона `/m`
- **МЗ (`/medui [ID]`)**: настраиваемая таблица ЕЦП, 1-клик РП + `/medhelp`, `/heal`, `/medcard`, `/analysis`, опциональное Авто-РП на ручной ввод `/medhelp` и `/heal`
- **Локальный Damage Informer (`/dmglog`)**: выключен по умолчанию; индикатор последнего попадания в `/hud` и журнал до 25 записей через `onSendGiveDamage` / `onSendTakeDamage`
- **Планировщик GNEWS по точному времени (`ЧЧ:ММ:СС`)**: обратный отсчёт в `/hud`, предупреждение за 15 с и кнопка брони волны в лидерскую рацию `/l`
- **Лектор и Собесы (`/lect`, `/lectstop`)**: 7 готовых редактируемых шаблонов (собеседование, лекции, правила рации, Миранда, ПРО, инструктажи МЗ/МО) с поддержкой паузы `<0>` и таймеров `<мс>` (`helper_lecturer.json`)

### Меню на СКМ, Взаимодействие с игроками и Авто-стробы
- **Быстрое меню на СКМ (`VK_MBUTTON` / `/wheelmenu`)**: всплывает у курсора, содержит до 6 закреплённых отыгровок РП-движка, контекстные кнопки вашей фракции и общие команды
- **Прокачка меню по прицелу (`ПКМ + X/R/E`)**: настраиваемая клавиша активации, опциональное Авто-РП, кнопки МВД (`/su`, `/ticket`, `/cuff`, `/uncuff`, `/search`), МЗ (`/medhelp`, `/heal`) и `/history`
- **Авто-стробы при сирене**: в «Транспорте и Визуале» — авто-включение стробоскопов при активной сирене (`isCarSirenOn`) с восстановлением фар; плюс **Спорт-режим (`Alt + W` / `Shift + W`)** и обычный круиз (`C`, `W`/`S`) с паузой в поворотах (`A`/`D`) и на тормозе (`S`/`Space`) *(с предупреждением о риске бана)*
- **Свободная камера («Дрон» / `/cam`)**: строго выключена по умолчанию, включается вручную в «Транспорте и Визуале» или командой `/cam` для скриншотов и осмотра построек (с предупреждением о правилах сервера; управление `WASD` + `Space`/`Shift` + стрелки/мышь, безопасные опкоды камеры GTA SA)

### Чат-комбайн, AutoEdit, Викторины, GPS и Утилиты
- **Фильтр чата / анти-спам**: скрытие чужих `/ad` (с белым списком ключевых слов со звуком), эфиров, системного флуда, свой чёрный список и триггеры (строго после всех парсеров)
- **Авто-перенос длинных строк**: делит длинные фразы по словам (до 4 частей с `...`) в чате и `/me`, `/do`, `/r`, `/f`, `/d`, `/s`, `/w`, `/t`, `/u`, сохраняя команду, ID и тег рации
- **Быстрые утилиты**: `/rec [сек]` (реконнект), `/hist [ID/ник]` (история ников), `/buyfast` (опциональная быстрая покупка в 24/7/аптеке), раскладка в чате (`F2`), авто-тег рации, друзья (`/fadd`/`/fdel`/`/friends`), `/ss`, `/clog`, финансы, опциональный счётчик активности/AFK в `/hud`, **Личный GPS (`/wp`)**, **6 пресетов фракций**, **Экспорт/Импорт v2 (`helper_export.json`)**
- **AutoEdit v2**: однопроходный движок, `1971` правило + авто-очистка, Auto-Send, самообучение и история
- **СМИ, Викторины и Телефонная книга**: **270+ анаграмм** без повторов (`/anag [0-5]`), **Режиссёр викторин (`/quiz`)** с авто-детектом SMS, исправленный `/find` (не перекрывает `/gps`), точный кэш онлайна, `/calln`, `/smsn`, `/lsms`, `/hud` и `/calc`

## Установка

Подробная инструкция: [INSTRUCTION_RU.md](INSTRUCTION_RU.md)

1. Установите **CLEO 4** и **SAMPFUNCS**
2. Установите **MoonLoader v0.26+** (полную сборку с библиотеками `mimgui`, `SAMP.Lua`, `memory`, `bit`, `encoding`, `json`, `ffi`)
3. Скачайте **`helper_core.lua`**: https://github.com/estatyq/advancelua/raw/main/helper_core.lua
4. Скопируйте в `GTA San Andreas/moonloader/`
5. Запустите игру, нажмите **F11** или введите `/helper`

## Горячие клавиши и команды

| Клавиша / Команда | Действие |
|-------------------|----------|
| `F11` / `/helper` | Открыть/закрыть главное меню |
| `СКМ` / `/wheelmenu` | Быстрое меню избранных РП-отыгровок и фракционных команд |
| `ПКМ + X` *(или `R`/`E`)* | Меню взаимодействия с игроком под прицелом (документы, МВД, МЗ, история) |
| `F2` (в чате) | Конвертировать раскладку набранного текста (EN↔RU) |
| `C` / `W` / `S` и `Alt/Shift + W` | Круиз-контроль и Спорт-режим (в транспорте) |
| `J` / `N` | Стробоскопы и переключение из 19 режимов |
| `/loc [1|2]` / `/tloc` / `/tedit` | Конструктор `/location`: каталог 522, реестр и точный редактор |
| `/tcopy` / `/tpaste` / `/tdup` | Копирование/вставка координат и дубликат объекта в `/location` |
| `/suw [ID]` / `/medui [ID]` / `/dmglog` | Меню розыска УК/АК (МВД), ЕЦП (МЗ) и журнал урона |
| `/lect [N]` / `/lectstop` | Запуск и остановка диктора / лекций |
| `/cam` | Свободная камера «Дрон» (только при включении в настройках или командой) |
| `/buyfast` | Быстрая покупка выбранного товара в открытом 24/7 / аптеке |
| `/rec [сек]` / `/hist [ID/ник]` | Быстрый реконнект и история смены ников |
| `/quiz` / `/anag [0-5]` | Мини-окно викторин и анаграммы без повторов |
| `/wp` / `/wpsave` / `/wpclear` | Личный GPS и метка на радар с расстоянием в `/hud` |
| `/lsms` / `/calln` / `/smsn` | Быстрое SMS и звонки по базе игроков |
| `/hud` / `/calc` / `/ss` / `/clog` | Компактный HUD, калькулятор, скрин отчёта и поиск по чату |

## Настройки

Настройки сохраняются в `moonloader/config/helper_settings.json`, база игроков — `helper_db.json`, правила AutoEdit — `helper_mm_rules.json`, лектор — `helper_lecturer.json`, УК/АК/ЕЦП — `helper_codex.json`, реестр локаций — `helper_locations.json`, единый бэкап v2 — `helper_export.json`.  
История AutoEdit, кандидаты самообучения, РП-отыгровки и ЧС СМИ сохраняются в `%LOCALAPPDATA%\helper_*.json`.

## История версий

- **v2.6** (26.11.2026) — **Полный цикл Фаз 2–6 + оптимизация LuaJIT**:
  - Оптимизированы верхнеуровневые локальные переменные (`308` → `48/150`) и upvalues (`81` → `10/45`) для стабильной компиляции LuaJIT.
  - **Фаза 2 (`v2.2`)**: меню на СКМ, настраиваемая клавиша `ПКМ + X/R/E` с действиями МВД/МЗ, авто-стробы при сирене.

  - **Фаза 4 (`v2.4`)**: МВД `/suw` (УК/АК, мегафон, Авто-РП), МЗ `/medui` (ЕЦП, Авто-РП), опциональный Damage Informer.

- **v2.1** (25.11.2026) — Умный фильтр чата, авто-перенос длинных строк, `/rec`, `/hist`.
- **v2.0** (25.11.2026) — Режиссёр викторин (`/quiz`), 270+ анаграмм, Личный GPS (`/wp`), пресеты фракций, экспорт, Спорт-режим, фикс `/gps` vs `/find`.
- **v1.8–v1.9** (25.11.2026) — `onSendCommand` Авто-РП, AutoEdit v2, «Утилиты и Чат», телефонная книга, `/hud`, `/calc`.
