# Universal Helper Platform v4.0

Универсальный игровой помощник для **GTA San Andreas — SA-MP** (сервера Advance RP).  
Построен на **MoonLoader** (Lua) с GUI **mimgui**, событиями **SAMP.Lua** и **SAMPFUNCS**.

[English version](README_EN.md) | [Дорожная карта](ROADMAP.md) | [Инструкция по эксплуатации](INSTRUCTION_RU.md)

---

## Возможности

### v4.0 — Dashboard, Dynamic Island, Кодексы `/laws`, Умный МВД/ЧС и Визуальный редактор колеса
- **Главная страница (`dashboard`, вкладка по умолчанию) и Единый профиль:** сводка сессии (сервер, фракция, PayDay, локация, таймеры смены, быстрые действия и статус `ENV_CAPS`) + единый профиль персонажа с live-подстановкой тегов `{name}`, `{surname}`, `{fullname}`, `{rank}`, `{callsign}`, `{subdiv}`, `{badge}`, `{ended}` в РП-движок, Лектор, Патруль и Посты МО.
- **Dynamic Island HUD (`/island`) и Радар рядом:** компактная скруглённая верхняя пилюля (район SA + квадрат, PayDay, статус смены, очередь тостов, `HideCursor` + `NoInputs` при закрытом F11) и опциональный (выкл. по умолчанию) радар друзей и ЧС в зоне стрима.
- **Кодексы и Уставы (`/laws`), Поиск и опциональный BYOK AI:** встроенная структурированная база **Advance RP Blue** (УК, ПДД, АК, ПК, Уставы МВД/МО/МЗ, Правила КПП, Присяга, ЕЦП, ПРО, ППЭ) со **строгой изоляцией серверов** (на `Red`/`Green`/`Lime`/`Chocolate` загружается локальный `helper_laws_<server>.json`, статьи `Blue` никогда не подставляются), крупный шрифт, избранное, оффлайн-поиск и опциональный BYOK AI (выкл. по умолчанию, ключ только в RAM).
- **Умные `/sus`, `/ticket`, `/takelic` и Мульти-ЧС (`/bl`):** переработанный `/suw` (`/sus`) с главами и подсказками, окно `/ticket` (ПДД первым списком; при аргументах `/ticket id сумма причина` проходит нативно), `/takelic` с основаниями и редактируемым РП, локальный мульти-ЧС организаций (`/bl`, `helper_faction_bl.json`, опциональный URL-sync выкл. по умолчанию).
- **Визуальный редактор колеса СКМ, `/stoprp`, «Тест без чата», Авто-скрин и `/hexit`:** 8 настраиваемых слотов колеса СКМ с предпросмотром на `ImDrawList`, мгновенная остановка всех РП-потоков `/stoprp`, безопасный Dry-Run тестер без отправки в чат, опциональный авто-скриншот F8 после докладов (выкл. по умолчанию) и мягкая выгрузка `/hexit`.

### Адаптивная платформа под фракции и плашки зависимостей (`v3.0`)
- **Автонастройка под фракцию (`F11` шапка + автодетект):** интерфейс, верхняя панель быстрого доступа, меню СКМ, меню цели (`ПКМ+X`), справочник и `/hud` автоматически подстраиваются под **МО (Армия: СВ / ВВС / ВМФ)**, **МВД / ФБР**, **МЗ**, **СМИ**, **Мэрию**, **Банды/Мафии** или **Гражданского** без визуального шума от чужих фракций — с чекбоксом **«Все модули»** в 1 клик.
- **Модуль МО / Армия (`/army`, `/post`, `/chs`):** посты (`КПП-1`, `КПП-2`, `Вышка`, `Склад БП`, `Авианосец`) с кодами обстановки и таймером доклада `/r` в `/hud`, конвой БП (38 зон SA + `A-1..H-8`), быстрая кнопка ЧС `/chs`, радар ключевых слов рации, поиск по **Уставу МО**, пресеты Присяги/КПП для Лектора, военный пресет `/loc 4` (*Блокпост / КПП (МО)*) и встроенный `/dmglog`.
- **Подтверждённое сервером Авто-РП и `/sp`:** отыгровки после подтверждения действия сервером + команда `/sp [команда]` (например `/sp healme`) для разового быстрого ввода без Авто-РП в бою, а также индикатор совпадения кодекса с текущим сервером Advance RP (`Blue`, `Red`, `Green`, `Lime`, `Chocolate`).
- **Плашки зависимостей (`ENV_CAPS`):** модули проверяют MoonLoader, SAMPFUNCS, CLEO, SAMP.Lua, mimgui, `memory`, `bit` и при нехватке показывают понятную плашку-подсказку *(«Требуется ... — сейчас не установлено»)* плюс сводку диагностики в «Утилитах».

### Конструктор локаций `/location` PRO — полный бесплатный набор (`location_builder`)
- **Каталог 522 объектов (`/loc 1` / `/tloc 1`)**: все 522 официальных ID объектов со страницы `adv-rp.com/decor` в 7 категориях, поиск по ID и названию, сортировка, избранное, недавние, компактный/карточный режим и опциональная подгрузка превью-картинок в `moonloader/config/decor_cache/`
- **Точный редактор поверх штатного `/location` (`/tedit`, `/tcopy`, `/tpaste`, `/tdup`)**: живой локальный предпросмотр через `sampGetObjectHandleBySampId` / `setObjectCoordinates` / `setObjectRotation` (матрица GTA SA), сдвиг по `X/Y/Z` (`0.01–2.0`), поворот по `RX/RY/RZ` (`1°–90°`, горизонт), Undo/Redo до сохранения, копирование и вставка (всё / только `Z` / только углы / со смещением для стыковки стен) и дубликат объекта
- **Реестр сохранённой локации (`/loc 2` / `/tloc 2`)**: сохранение объектов в `helper_locations.json` по серверу и персонажу по факту серверного сохранения, пошаговый помощник правки/удаления из середины списка и экспорт/импорт чертежей (`helper_loc_blueprint.json`)
- **PRO-вкладка «Ряд и Сцены» (`/loc 4` / `/tloc 4`)**: авто-расстановка рядов/заборов с шагом вдоль угла 1-го объекта и 4 готовых пресета сцен (*Блокпост МВД*, *Полевой госпиталь МЗ*, *Сцена концерта СМИ*, *Пресс-конференция Мэрии*) с расчётом от позиции игрока
- Автоматический резерв `/tloc`, если команда `/loc` уже занята

### МВД, Патруль-ассистент, МЗ и Старший состав (`faction_tools`, `lecturer`, `gnews`)
- **МВД (`/suw [ID]`)**: редактируемый справочник УК (20 статей) и АК (10 статей) с пресетами серверов Blue / Red / Green / Chocolate (`helper_codex.json`), 1-клик РП + `/su` или `/ticket` (ручной `/su` не тронут), опциональное Авто-РП на `/cuff`, `/uncuff`, `/search`, `/putpl`, `/arrest` и 4 пресета мегафона `/m`
- **Патруль-ассистент МВД (`/patrol [start|rep|chase|stop]`)**: доклады в рацию в 1 клик, автоопределение района и квадрата San Andreas (`A-1..H-8`), кнопка погони с координатами и таймер следующего доклада в `/hud`
- **МЗ (`/medui [ID]`)**: настраиваемая таблица ЕЦП, 1-клик РП + `/medhelp`, `/heal`, `/medcard`, `/analysis`, опциональное Авто-РП на ручной ввод `/medhelp` и `/heal`
- **Локальный Damage Informer (`/dmglog`)**: выключен по умолчанию; индикатор последнего попадания в `/hud` и журнал до 25 записей через `onSendGiveDamage` / `onSendTakeDamage`
- **Планировщик GNEWS по точному времени (`ЧЧ:ММ:СС`)**: обратный отсчёт в `/hud`, предупреждение за 15 с и кнопка брони волны в лидерскую рацию `/l`
- **Лектор и Собесы (`/lect`, `/lectstop`)**: 7 готовых редактируемых шаблонов (собеседование, лекции, правила рации, Миранда, ПРО, инструктажи МЗ/МО) с поддержкой паузы `<0>` и таймеров `<мс>` (`helper_lecturer.json`)

### Темы ImGui, Трекер рынка `/price`, Меню и Утилиты
- **6 тем оформления + масштаб (`F11`)**: *Стандарт*, *МВД*, *МЗ*, *СМИ*, *Кибер*, *Светлая* + слайдеры прозрачности фона (`0.65–1.00`) и масштаба шрифта (`0.85–1.35`)
- **Трекер цен рынка (`/price [запрос]`)**: фоновый парсинг цен из `/ad` (исключая «договорная» и номера телефонов), статистика `Мин / Средн / Макс`, база `helper_market.json` (до 250 лотов) с быстрыми кнопками `Звонок` / `SMS`
- **Быстрое меню на СКМ (`VK_MBUTTON` / `/wheelmenu`) и меню по прицелу (`ПКМ + X/R/E`)**: избранные отыгровки РП-движка, контекстные кнопки фракции, МВД/МЗ и `/history`
- **Авто-стробы и Дрон (`/cam`)**: авто-включение стробоскопов при сирене (`isCarSirenOn`), Спорт-режим (`Alt+W`/`Shift+W`), круиз (`C`/`W`/`S`), и опциональная свободная камера `/cam` (выключена по умолчанию)
- **Чат-комбайн и AutoEdit v2**: фильтр чата / анти-спам, авто-перенос длинных строк, раскладка `F2`, `/rec`, `/hist`, `/buyfast`, `/wp` GPS, 6 пресетов фракций, Экспорт v2 (`helper_export.json`), AutoEdit v2 (`1971` правило), `/quiz`, `270+` анаграмм (`/anag`), `/hud`, `/calc`

## Установка

Подробная инструкция: [INSTRUCTION_RU.md](INSTRUCTION_RU.md)

1. Установите **CLEO 4** и **SAMPFUNCS**
2. Установите **MoonLoader v0.26+** (полную сборку с библиотеками `mimgui`, `SAMP.Lua`, `memory`, `bit`, `encoding`, `json`, `ffi`)
3. Скачайте **`helper_core.lua`**: https://github.com/estatyq/advancelua/raw/main/helper_core.lua
4. Скопируйте в `GTA San Andreas/moonloader/`
5. Запустите игру, нажмите **F11** или введите `/helper`

## Горячие клавиши и команды

| Клавиша / Команда | Действие |
|-------------------|----------|
| `F11` / `/helper` | Открыть/закрыть главное меню |
| `СКМ` / `/wheelmenu` | Быстрое меню избранных РП-отыгровок и фракционных команд |
| `ПКМ + X` *(или `R`/`E`)* | Меню взаимодействия с игроком под прицелом (документы, МВД, МЗ, история) |
| `F2` (в чате) | Конвертировать раскладку набранного текста (EN↔RU) |
| `C` / `W` / `S` и `Alt/Shift + W` | Круиз-контроль и Спорт-режим (в транспорте) |
| `J` / `N` | Стробоскопы и переключение из 19 режимов |
| `/loc [1|2|3|4]` / `/tloc` / `/tedit` | Конструктор `/location`: каталог 522, реестр, редактор и PRO (Ряд / Сцены) |
| `/tcopy` / `/tpaste` / `/tdup` | Копирование/вставка координат и дубликат объекта в `/location` |
| `/suw [ID]` / `/sus [ID]` / `/ticket [ID]` / `/takelic [ID]` | МВД: розыск по главам УК, штрафы ПДД/АК, изъятие прав и мегафон |
| `/laws [запрос]` / `/bl [ID/ник]` | Кодексы/Уставы (строгая изоляция серверов) + оффлайн-поиск/BYOK AI и Мульти-ЧС |
| `/island` / `/stoprp` / `/hexit` | Dynamic Island HUD, экстренная остановка всех РП и мягкая выгрузка скрипта |
| `/patrol` / `/medui [ID]` / `/dmglog` | Патруль-ассистент МВД, МЗ ЕЦП и журнал урона |
| `/price [запрос]` | Трекер рыночных цен из `/ad` (Мин / Средн / Макс, `Звонок` / `SMS`) |
| `/lect [N]` / `/lectstop` | Запуск и остановка диктора / лекций |
| `/cam` | Свободная камера «Дрон» (только при включении в настройках или командой) |
| `/buyfast` | Быстрая покупка выбранного товара в открытом 24/7 / аптеке |
| `/rec [сек]` / `/hist [ID/ник]` | Быстрый реконнект и история смены ников |
| `/quiz` / `/anag [0-5]` | Мини-окно викторин и анаграммы без повторов |
| `/wp` / `/wpsave` / `/wpclear` | Личный GPS и метка на радар с расстоянием в `/hud` |
| `/lsms` / `/calln` / `/smsn` | Быстрое SMS и звонки по базе игроков |
| `/hud` / `/calc` / `/ss` / `/clog` | Компактный HUD, калькулятор, скрин отчёта и поиск по чату |

## Настройки

Настройки сохраняются в `moonloader/config/helper_settings.json`, база игроков — `helper_db.json`, правила AutoEdit — `helper_mm_rules.json`, лектор — `helper_lecturer.json`, УК/АК/ЕЦП — `helper_codex.json`, реестр локаций — `helper_locations.json`, единый бэкап v2 — `helper_export.json`.  
История AutoEdit, кандидаты самообучения, РП-отыгровки и ЧС СМИ сохраняются в `%LOCALAPPDATA%\helper_*.json`.
