# Глобальный план развития — Universal Helper Platform (Advance RP)

Единая дорожная карта развития **`helper_core.lua`** (GTA San Andreas / SA-MP / MoonLoader) с учётом лучших механик популярных хелперов для **Advance RP** (*HorAssist*, *FBI Helper*, *MedHelper*, *MultiAHK*, *TitanLocation*), при сохранении архитектуры «один файл без лишних внешних зависимостей».

## Фаза 1 (v2.1) — Чат-комбайн: Фильтр чата + Перенос строк + `/hist` + `/rec` ✅

Универсальные улучшения качества жизни, работающие в любой организации и на гражданке.

- [x] **Умный фильтр чата / анти-спам** *(идея FBI Helper)*:
  - Встраивается в `sampev.onServerMessage` **строго после** всех парсеров телефонной книги, SMS-викторины, ЧС и трекера финансов, чтобы фильтрация никогда не ломала автоматику.
  - Переключатель **«Скрывать чужие `/ad`»** + **белый список ключевых слов** (например: `дом, биз, булка, нрг`) — совпавшие объявления пропускаются в чат и сопровождаются звуком.
  - Переключатели **скрытия эфиров (`/t`, `/u`)** и **системного флуда / подсказок**.
  - Пользовательский **чёрный список стоп-слов** (скрывает любые строки чата с указанными фразами) и **триггеры уведомлений** (звуковой сигнал при совпадении).
- [x] **Авто-перенос длинных строк** *(идея MedHelper)*:
  - Перехват слишком длинных сообщений в обычном чате (`sampev.onSendChat`) и в ролевых/чат-командах `/me`, `/do`, `/r`, `/f`, `/d`, `/s`, `/w`, `/t`, `/u` (`sampev.onSendCommand`) при превышении настраиваемого лимита (по умолчанию `108` символов CP1251, диапазон `70–122`).
  - Аккуратное разбиение по границам слов до 4 частей (`...`), автоматическая подстановка той же команды и тега рации, отправка продолжения через `scheduleTask` (по умолчанию `650` мс) с флагом `rp_sending_internal = true` (без зацикливания и без спама в Авто-РП).
  - Игнорирование технических команд (`/ad`, `/gnews`, `/edit`, `/su`, `/sms`, `/c`, `/pay`).
- [x] **Быстрый реконнект `/rec [сек]`** *(идея MedHelper)*:
  - Переподключение к серверу без перезапуска игры через `sampDisconnectWithReason(false)` → настраиваемая пауза → `sampSetGamestate(1)` (отмена по `/rec 0`).
- [x] **Быстрая история ников `/hist [id]`** *(идея MedHelper)*:
  - Принимает ID игрока (или часть ника), подставляет точный никнейм и отправляет `/history <Nick>` (удобно для проверок и отчётов).

## Фаза 2 (v2.2) — Интерактив и Управление: Меню на СКМ + Прокачка `ПКМ + X/R/E` + Авто-стробы ✅

- [x] **Быстрое радиальное/компактное меню на колёсико мыши — СКМ (`VK_MBUTTON = 0x04`)** *(идея FBI Helper)*:
  - Открывается прямо у позиции курсора при нажатии СКМ (не срабатывает при открытом чате, диалогах или прицеливании ПКМ).
  - Отображает избранные многострочные отыгровки из РП-движка (1 клик → `playRp`) и быстрые контекстные кнопки под текущую фракцию (СМИ: `/edit`, `/quiz`, `/anag`, `/mmefir`; МВД: `/co`, `/m`, `/patrol`; МЗ: `/medhelp`, `/heal`; общие: `/c 60`, `/ss`, `/mask`, `/healme`, `/lock`, `/e`).
  - Отключается в настройках или при желании переназначается на другую клавишу.
- [x] **Прокачка меню взаимодействия по прицелу (`ПКМ + X / R / E`)** *(идея MedHelper + FBI Helper)*:
  - Возможность выбрать клавишу активации (`X`, `R` или `E`).
  - Расширенный блок фракционных действий прямо на игрока в прицеле:
    - Для **МВД**: розыск (`/su`), штраф (`/ticket`), наручники (`/cuff` / `/uncuff`), обыск (`/search`).
    - Для **МЗ**: лечение в стационаре (`/medhelp`), лечение в карете (`/heal`).
    - Общее: история смены ников (`/history <Nick>`).
  - Опция автоматической РП-отыгровки при нажатии кнопки.
- [x] **Авто-стробы при сирене** *(идея MedHelper)*:
  - Отдельная галочка в «Транспорте и Визуале»: фоновый опрос `isCarSirenOn(car)` — при включении мигалки/сирены на патрульной машине или скорой стробоскопы включаются автоматически, при выключении — гаснут и восстанавливают фары через `restoreAllLights(car)`.

Инструмент для лидеров, заместителей и организаторов РП-мероприятий, убирающий рутину при создании сцен и построек через `/location` (и полностью бесплатный в составе `helper_core.lua`).

- [x] **1. Каталог 522 объектов `/location` (`/loc 1` / `/tloc 1`)**:
  - Встроенный каталог всех **522 официальных ID объектов** со страницы `adv-rp.com/decor` (кэш ID уже собран), разбитый по категориям (стены, заборы, сцена/освещение, мебель, техника, уличный декор, спецобъекты).
  - Поиск по ID и названию, сортировка (по каталогу, ID, названию), компактный и карточный вид.

  - Экспорт и импорт готовых чертежей локаций в JSON для переноса или совместной работы.

  - Если `/loc` уже занят другим скриптом или сервером, автоматический резерв `/tloc` с уведомлением в чат.

## Осознанно НЕ включаем

- **Авто-ввод пароля и пин-кода** — небезопасно хранить пароли от аккаунта открытым текстом в конфиге; несовместимо с частью лаунчеров / OpenMP.
- **Оффлайн-база координат всех 1000+ домов по ID** — статичная база быстро устаревает при добавлении домов и сильно раздувает скрипт, а штатный `/gps → Поиск по номеру дома` уже работает без перехвата после фикса в v2.0.

## Архитектурные и технические правила (обязательны для всех фаз)

1. **Единый скрипт:** весь функционал живёт в `helper_core.lua`, без обязательных нестандартных библиотек сверх базовой сборки MoonLoader (`mimgui`, `SAMP.Lua`, `memory`, `bit`, `encoding`, `ffi`, опциональный `json`).
2. **Кодировка:** `helper_core.lua` — строго **Windows-1251 (CP1251)** с **CRLF (`\r\n`)**; документация (`README*.md`, `ROADMAP.md`) — **UTF-8**.
3. **Потокобезопасность ImGui:** никаких прямых вызовов `samp*`, GTA-координат/маркеров, `getPlayerMoney`, `addOneOffSound` или `lua_thread.create` внутри `imgui.OnFrame` / `drawSettings` — любые действия строго через `queueTask(...)` / `scheduleTask(...)`.
4. **Безопасность строк и буферов:** только `imgui.TextUnformatted(...)`, нечётные размеры буферов `imgui.new.char[N]` с `ffi.sizeof(buf)`, строгое соблюдение разделения CP1251 (внутри Lua) ↔ UTF-8 (в ImGui).
5. **Обязательная верификация после каждой фазы:** прогон `verify_helper.py` (CP1251, 0 NUL/control bytes, баланс токенов Lua, аудит всех `OnFrame`-окон, юнит-проверки логики) + чистый `git status` перед коммитом.
